# Локальная система распознавания и диаризации речи (Whisper & WhisperX)

Этот репозиторий содержит набор скриптов для создания полностью автономной системы расшифровки аудиозаписей на вашем компьютере. Решение позволяет не только превращать речь в текст, но и автоматически разделять его по говорящим (диаризация), что идеально подходит для анализа лекций, интервью и совещаний.

В основе лежат мощные open-source модели **OpenAI Whisper** и **WhisperX**, что гарантирует высокую точность и полную приватность ваших данных.

## ✨ Ключевые возможности

*   **Два режима работы:**
    1.  **Простая транскрибация (Whisper):** быстрое получение сплошного текста из аудио. Идеально для монологов, лекций.
    2.  **Транскрибация с диаризацией (WhisperX):** получение структурированного диалога с разметкой по спикерам (`SPEAKER_01`, `SPEAKER_02`). Отлично подходит для совещаний, интервью.
*   **Приватность:** все ваши аудиозаписи и текстовые расшифровки остаются на вашем компьютере. Никакие данные не передаются третьим лицам.
*   **Бесплатно и Open Source:** проект построен на бесплатных инструментах. Вы не платите за подписку или поминутное распознавание.
*   **Высокая точность:** используется модель `large-v3` от OpenAI, которая является одной из самых точных для распознавания речи, включая русский язык.
*   **Ускорение на GPU:** простая транскрибация поддерживает NVIDIA/CUDA и отдельный режим Intel GPU/OpenVINO. Диаризация пока остается NVIDIA-only.
*   **Простая установка:** для каждого режима предусмотрены bash-скрипты, которые автоматизируют настройку окружения.

## 🚀 Быстрый старт: сначала выберите GPU

### Шаг 1. Клонируйте репозиторий

```bash
git clone https://github.com/empenoso/offline-audio-transcriber
cd offline-audio-transcriber
```

### Шаг 2. Запустите помощник выбора

```bash
chmod +x choose_transcription_setup.sh
./choose_transcription_setup.sh
```

Помощник ничего не устанавливает и не требует `sudo`. Он проверяет PCI-видеоконтроллеры и доступные ядру render/compute-устройства, после чего выводит нужный установщик:

- NVIDIA — `./whisper_transcribe_setup.sh`;
- Intel — `./whisper_openvino_setup.sh`;
- NVIDIA + Intel — показывает оба варианта и рекомендует тот, чей драйвер уже работает;
- GPU не найден — установка не запускается; проверьте BIOS, подключение устройства и видимость GPU через `lspci`.

`PCI display controller` означает физический видеоконтроллер класса VGA/3D/Display, видимый через PCI. `GPU render/compute device` означает интерфейс `/dev/dri/renderD*`, через который OpenVINO получает доступ к вычислениям. В WSL, контейнере или виртуальной машине PCI-контроллер может быть скрыт, а проброшенное render-устройство — доступно; для выбора Intel/OpenVINO этого достаточно, окончательную проверку выполняет установщик OpenVINO.

Рекомендация помощника относится к обычной транскрибации без разделения по спикерам. Диаризация в текущей версии поддерживается только на NVIDIA.

### Шаг 3. Следуйте найденной ветке

| Возможности | NVIDIA/CUDA | Intel/OpenVINO | NVIDIA + WhisperX |
| :--- | :--- | :--- | :--- |
| **Назначение** | Транскрибация | Транскрибация | Транскрибация и диаризация |
| **Установщик** | `whisper_transcribe_setup.sh` | `whisper_openvino_setup.sh` | `whisperx_diarization_setup_ubuntu24.sh` или `...ubuntu25.sh` |
| **Рабочее окружение** | `.venv` | `.venv-openvino` | Docker |
| **Скрипт запуска** | `whisper_transcribe.py` | `whisper_transcribe_openvino.py` | `whisperx_diarization.py` |
| **CUDA нужна** | Да | Нет | Да |
| **Диаризация** | Нет | Нет | Да |

Окружения `.venv` и `.venv-openvino` независимы. Перед сменой варианта выполните `deactivate`, затем активируйте нужное окружение. Не запускайте Intel-скрипт из `.venv` и NVIDIA-скрипт из `.venv-openvino`.

Для обычной транскрибации общий порядок одинаков: создайте папку `audio`, положите в нее записи, активируйте соответствующее окружение и укажите папку `results` для результата.

```bash
mkdir -p audio results
```

## Вариант A: NVIDIA/CUDA — простая транскрибация

Этот метод идеально подходит для быстрой расшифровки аудиозаписей без необходимости разделять речь по спикерам.

### Установка

Для автоматической установки всех необходимых компонентов (Python, FFmpeg, NVIDIA Drivers, CUDA, PyTorch) используется специальный bash-скрипт.

```bash
chmod +x whisper_transcribe_setup.sh
./whisper_transcribe_setup.sh
```

Скрипт обновит систему, установит драйверы NVIDIA (если необходимо), CUDA, создаст виртуальное окружение `.venv` и установит Python-библиотеки.

Если был установлен или обновлен драйвер NVIDIA, перезагрузите компьютер, затем проверьте его:

```bash
sudo reboot
# после перезагрузки
nvidia-smi
```

### Работа

1.  **Поместите ваши аудиофайлы** (поддерживаются `.mp3`, `.wav`, `.m4a`) в любую папку, например, `audio/`.

2.  **Активируйте окружение NVIDIA:**
    ```bash
    source .venv/bin/activate
    ```

3.  **Запустите скрипт `whisper_transcribe.py`:**

    *   **Простой запуск** (поиск аудио в текущей папке):
        ```bash
        python3 whisper_transcribe.py
        ```

    *   **Указание параметров вручную** (папка с аудио, модель, папка для результатов):
        ```bash
        python3 whisper_transcribe.py ./audio large ./results
        ```

### Результаты

После выполнения скрипта в выходной папке вы найдете:
*   **`.txt` файл** для каждой аудиозаписи с полным текстом.
*   **`.srt` файл** для каждой аудиозаписи с субтитрами и таймкодами.
*   **`all_transcripts.txt`** — один файл, содержащий все расшифровки подряд.

## Вариант B: Intel GPU/OpenVINO — простая транскрибация

Этот независимый вариант не требует CUDA и не выполняет диаризацию. Он предназначен для Ubuntu с интегрированной графикой Intel или дискретной Intel Arc.

### Установка

```bash
chmod +x whisper_openvino_setup.sh
./whisper_openvino_setup.sh
```

Установщик:

1. Проверяет наличие Intel VGA/3D/display-контроллера через PCI.
2. Просит явное подтверждение перед установкой системного Intel OpenCL runtime.
3. Создает отдельное окружение `.venv-openvino` и устанавливает в него OpenVINO, OpenVINO GenAI, NumPy и клиент Hugging Face Hub.
4. Проверяет наличие FFmpeg, NumPy, OpenVINO и OpenVINO GenAI, а затем убеждается, что устройство `GPU` действительно доступно OpenVINO.

Установщик ставит только необходимые системные зависимости: Python venv, FFmpeg, OpenCL loader и Intel OpenCL ICD. Level Zero, PyTorch, Optimum, CUDA, медиа-драйверы и дополнительные диагностические утилиты не требуются и автоматически не устанавливаются.

Если пользователь был только что добавлен в системную группу доступа к GPU или драйвер был обновлен, может потребоваться выход из сеанса или перезагрузка, после чего установщик следует запустить повторно.

Полный порядок при сообщении о необходимости перезапуска:

```bash
sudo reboot
# после перезагрузки вернитесь в каталог проекта
./whisper_openvino_setup.sh
source .venv-openvino/bin/activate
python whisper_transcribe_openvino.py --check
```

Проверка должна показать устройство `GPU`. Если отображается только `CPU`, Intel-драйвер или права группы `render` еще не применились.

### Работа

```bash
source .venv-openvino/bin/activate
python whisper_transcribe_openvino.py ./audio medium ./results
```

При первом запуске готовая модель OpenVINO FP16 загружается из официального пространства `OpenVINO` на Hugging Face и сохраняется в `.openvino_models/`. Локальная конвертация не выполняется. Последующие запуски используют локальную копию. Для гарантированно автономного запуска после загрузки модели добавьте `--offline`.

Полезные варианты:

```bash
# Только проверить доступные OpenVINO-устройства
python whisper_transcribe_openvino.py --check

# Автоопределение языка
python whisper_transcribe_openvino.py ./audio small ./results --language auto

# Явно разрешить OpenVINO выбрать GPU/CPU
python whisper_transcribe_openvino.py ./audio medium ./results --device AUTO

# Работать без сети с уже подготовленной моделью
python whisper_transcribe_openvino.py ./audio medium ./results --offline
```

Поддерживаются `wav`, `mp3`, `m4a`, `flac`, `ogg`, `opus` и `aac`. Результаты совместимы с обычным режимом: отдельные `.txt`/`.srt`, общий `all_transcripts.txt` и `transcripts_detailed.json`.

### Удаление Intel/OpenVINO

Установщик записывает в `.openvino-install-state` только те APT-пакеты, которых не было в системе до установки. Поэтому деинсталлятор не затрагивает ранее установленные пользовательские пакеты.

```bash
chmod +x whisper_openvino_uninstall.sh
./whisper_openvino_uninstall.sh
```

По умолчанию удаляются окружение `.venv-openvino`, добавленные установщиком APT-пакеты и добавленное им членство в группе `render`. Загруженные модели и кэш сохраняются. Чтобы удалить также модели и кэш:

```bash
./whisper_openvino_uninstall.sh --remove-data
```

Если OpenVINO устанавливался старой версией скрипта, списка новых APT-пакетов нет. В этом случае деинсталлятор безопасно удалит виртуальное окружение, но не будет угадывать, какие системные пакеты можно удалить.

## Вариант C: NVIDIA/CUDA — транскрибация с диаризацией

Этот метод использует Docker для решения проблем с зависимостями и позволяет не только транскрибировать аудио, но и определять, кто из спикеров говорил.

### Подготовка

1.  **Docker и NVIDIA GPU:** для работы требуется установленный Docker и видеокарта NVIDIA с актуальными драйверами.
2.  **Токен Hugging Face:** для диаризации необходим токен доступа.
    *   Получите его в [настройках профиля Hugging Face](https://huggingface.co/settings/tokens).
    *   Примите условия использования моделей [pyannote/speaker-diarization-3.1](https://huggingface.co/pyannote/speaker-diarization-3.1) и [pyannote/segmentation-3.0](https://huggingface.co/pyannote/segmentation-3.0).

### Шаг 1: Установка и настройка

Специальный скрипт автоматизирует установку Docker, NVIDIA Container Toolkit и настройку рабочего пространства.

1.  **Выберите установщик по версии Ubuntu:**
    ```bash
    # Ubuntu 24.04
    chmod +x whisperx_diarization_setup_ubuntu24.sh
    ./whisperx_diarization_setup_ubuntu24.sh

    # Ubuntu 25.x
    chmod +x whisperx_diarization_setup_ubuntu25.sh
    ./whisperx_diarization_setup_ubuntu25.sh
    ```

    Запускайте только один файл, соответствующий вашей версии ОС. Скрипт установит и настроит Docker, скачает образ WhisperX и создаст папки `audio`, `results` и конфигурацию `config.env`.

2.  **Настройте `config.env`:**
    Откройте файл `config.env` и вставьте ваш токен Hugging Face:
    ```ini
    HF_TOKEN=your_token_here
    ```

3.  **Перезагрузка:** После установки может потребоваться перезагрузка, чтобы применились права группы `docker`.
    ```bash
    sudo reboot
    ```

### Шаг 2: Запуск диаризации

1.  **Поместите аудиофайлы** в папку `audio/`.

2.  **Запустите скрипт-оркестратор:**
    *   Для проверки системы:
        ```bash
        python3 whisperx_diarization.py --check
        ```
    *   Для обработки всех файлов в папке `audio/`:
        ```bash
        python3 whisperx_diarization.py
        ```

### Шаг 3: Анализ результатов

Результаты для каждого аудиофайла будут сохранены в отдельной подпапке внутри `results/`. Вы получите структурированный протокол встречи.

**Было (обычный Whisper):**
> ...да, я согласен с этим подходом но нужно учесть риски которые мы не обсудили например финансовую сторону вопроса и как это повлияет на сроки я думаю нам стоит вернуться к этому на следующей неделе...

**Стало (WhisperX с диаризацией):**

> [00:01:15.520 --> 00:01:19.880] SPEAKER_01: Да, я согласен с этим подходом, но нужно учесть риски, которые мы не обсудили.

> [00:01:20.100 --> 00:01:22.740] SPEAKER_02: Например, финансовую сторону вопроса и как это повлияет на сроки?

> [00:01:23.020 --> 00:01:25.900] SPEAKER_01: Именно. Я думаю, нам стоит вернуться к этому на следующей неделе.
